# MenuHome · UI 设计文档

> 一句话定位：**常驻 macOS 状态栏的「个人桌面」** —— 像 iPhone 桌面一样收纳常用 App，支持文件夹分类，一键直达。
>
> 版本 v0.2 · 2025-09 · 范围：仅 App 快捷方式 · 风格：macOS 原生质感 · 技术目标：SwiftUI
>
> 变更记录：v0.2 —— 搜索栏不再常驻，改为按需弹出的覆盖层（面板打开后直接敲键盘或 ⌘F 呼出）；设计定稿，进入编码阶段。

## 1. 产品概述与设计原则

### 1.1 要解决的问题

- 常用 App 散落在 Launchpad / Finder / Spotlight 里，鼠标路径太长；
- Dock 放不下也分不了类；
- 想要一个「随叫随到、一眼看清、一击直达」的个人应用面板。

### 1.2 设计原则（做所有取舍时的判断依据）

| # | 原则 | 含义 |
|---|------|------|
| P1 | **一击即达** | 菜单栏图标 → 点 App，全程 2 次点击完成任务；任何功能入口不超过 2 层 |
| P2 | **似曾相识** | 交互隐喻全部来自 iOS 桌面：长按进编辑、拖拽建文件夹、点文件夹展开。零学习成本 |
| P3 | **原生融入** | 毛玻璃材质、系统字体、跟随深浅色、右键菜单风格与 macOS 一致，像系统自带功能 |
| P4 | **克制** | 面板只有一个主界面（桌面）。没有侧边栏、没有标签页、没有多余按钮 |

## 2. 信息架构与界面清单

```
MenuHome
├── 0. 菜单栏图标（常驻唯一入口）
│     ├── 左键单击 → 开/关「主面板」
│     └── 右键 → 快捷菜单（打开面板 / 设置 / 退出）
├── 1. 主面板「桌面」 ★唯一主界面（多页网格）
│     ├── App 格子（单击启动）
│     ├── 文件夹格子（单击展开 → 2. 文件夹覆盖层）
│     ├── 搜索（键盘直入，实时过滤）
│     └── 页点（分页）
├── 2. 文件夹展开层（面板内覆盖层，非新窗口）
├── 3. 编辑模式（抖动模式，面板内状态）
├── 4. 添加 App 覆盖层（面板内，编辑模式/右键进入）
├── 5. 设置窗口（独立小窗口）
└── 6. 右键菜单（贯穿 1–4 的上下文操作）
```

**关键形态决定**：文件夹展开、编辑模式、添加 App 都是**面板内的覆盖层/状态**，不是新窗口 —— 保证「桌面」这个空间隐喻始终成立，用户永远不会迷路。

## 3. 核心用户旅程

| 场景 | 路径 |
|------|------|
| 日常启动 | 点菜单栏图标 → 看到桌面 → 点 App → 启动，面板自动收起 |
| 归类整理 | 长按任意图标 → 抖动模式 → 把 A 拖到 B 上 → 自动建文件夹 → 点名字命名 |
| 找 App | 面板打开后直接敲键盘 → 实时过滤 → 回车启动第一个结果 |
| 新装了 App | 右键空白处 →「添加 App…」→ 搜索勾选 → 加入当前页空位 |
| App 被卸载了 | 图标变灰带「?」→ 点击时提示「未找到，是否从桌面移除？」 |

## 4. 界面设计（逐屏）

### 4.0 菜单栏图标（常驻入口）

```
  macOS 菜单栏（放大示意）：
  ┌────────────────────────────────────────────────┐
  │   ···  [ ⌂ ]   ···   🔋82%   📶   ⌕   21:58   │
  └─────────▲──────────────────────────────────────┘
            │ MenuHome 图标：18×18 圆角小房子轮廓（template image）
```

| 项目 | 规格 |
|------|------|
| 图形 | 圆角小房子**轮廓**（呼应产品名 menu-home），1.5pt 线宽；备用方案：3×3 圆点网格 |
| 渲染 | Template Image：自动适配深浅色、菜单栏高亮态 |
| 尺寸 | 18×18pt（@2x/@3x 资源） |
| 状态 | 常规（label 色 60%）/ 悬停（100%）/ 面板展开时（保持高亮，提示「点我收起」） |
| 左键 | 开/关面板（toggle），面板锚定图标正下方 |
| 右键 | 快捷菜单：`打开面板` ｜ `设置… ⌘,` ｜ `退出 MenuHome` |
| 可选 | 全局热键呼出/收起面板（默认 `⌥⌘H`，设置中可录制） |

> 设计取舍：不放「未读/数量」角标类信息 —— 这是个纯启动器，图标永远安静。

#### 结构与栅格（以默认 5 列 × 5 行 = 25 格/页为例）

| 区域 | 规格 |
|------|------|
| 面板整体 | 宽 = 40(左右边距) + 78(格宽)×N + 12(列距)×(N−1) → 4列 388 / **5列 478** / 6列 568；高 = 40 + 94×行数 → 5行 510（v0.2 去掉常驻搜索栏后减 44pt） |
| 网格 | 从左上角填充，行/列距 12/14，单元格见 [4.2](#42-app-格子cell) |
| 页点区 | 高 30，圆点 ⌀7：当前页 label 色，其余 35%；>1 页才显示 |
| 搜索入口 | 非常驻：按需覆盖层（见下，v0.2 变更），面板保持纯净 |

#### 分页

| 操作 | 行为 |
|------|------|
| 触控板双指滑动 / 鼠标滚轮 | 横向翻页（自然方向），带 260ms 位移动效 |
| ⌘← / ⌘→ | 键盘翻页 |
| 点页点 | 跳转对应页 |
| 编辑模式拖图标到面板左/右边缘 | 悬停 500ms 自动翻页 |
| 页数 | 由内容自动决定；最后一页至少保留 1 个空格便于继续添加 |

#### 搜索（覆盖层，非常驻）—— v0.2 变更

面板不再有常驻搜索栏，搜索改为按需覆盖层：

- **触发**：面板打开后直接敲键盘任意字符，或按 `⌘F`；
- **呈现**：覆盖层从面板顶部滑下 —— 圆角输入框（自动聚焦，已敲入的字符直接带入）+ 下方结果网格，背景桌面压暗模糊；
- 实时过滤：匹配 App 名 + 文件夹名（命中文件夹则整组显示）；命中文字高亮；
- 回车 = 启动第一个结果（文件夹则展开）；
- Esc = 关闭覆盖层回到桌面（不关面板）；
- 无结果：显示「没有找到“xx”」+ 弱化的「添加 App…」入口。

### 4.3 文件夹

#### 网格中的文件夹格子

```
   ┌────┐        iOS 同款隐喻：圆角矩形内 3×3 微缩图标
   │ ▒ ▒│        （最多取前 9 个 App 的真实小图标，
   │▒ ▒▒│          不足则留白；空文件夹显示虚线框+＋）
   │ ▒ ▒│
   └────┘
   开发工具          名称：11pt，1 行省略；默认名「新建文件夹」
```

#### 展开（面板内覆盖层）

```

        ║          （背景：桌面网格 模糊20px + 压暗30%）      ║
        ║                                                  ║
        ║        ╔════════════════════════════════╗        ║
        ║        ║            开发工具  ✎          ║ ← 点名称行内重命名
        ║        ║                                ║        ║
        ║        ║  ┌────┐ ┌────┐ ┌────┐ ┌────┐  ║        ║
        ║        ║  │▓▓▓▓│ │▓▓▓▓│ │▓▓▓▓│ │▓▓▓▓│  ║        ║
        ║        ║  └────┘ └────┘ └────┘ └────┘  ║        ║
        ║        ║  Xcode  iTerm  Warp  VS Code  ║        ║
        ║        ║                                ║        ║
        ║        ║  ┌────┐ ┌────┐ ┌────┐          ║        ║
        ║        ║  │▓▓▓▓│ │▓▓▓▓│ │▓▓▓▓│          ║        ║
        ║        ║  └────┘ └────┘ └────┘          ║        ║
        ║        ║  Docker Proxyman Instruments   ║        ║
        ║        ║                                ║        ║
        ║        ╚════════════════════════════════╝        ║
        ║                  ● ○        ← 卡片内页点(>12个时)  ║
        ║                                                  ║
        ║        （点背景 / Esc / 再点文件夹 = 收起）         ║
        ╚══════════════════════════════════════════════════╝
```

| 项目 | 规格 |
|------|------|
| 卡片 | 宽 380，高自适应（最多 4 列 × 3 行 = 12 格/页，超出分页）；材质比面板更亮一档（thickMaterial），圆角 21，大柔和阴影 |
| 打开动效 | 卡片从**文件夹格子原位**缩放放大（spring response 0.28 / damping 0.8），背景同时模糊压暗 —— iPhone 同款 |
| 关闭 | 点背景 / Esc / 再点该文件夹图标；动效反向 200ms |
| 重命名 | 单击卡片标题 → 行内文本框（预选中原名），回车/失焦确认；同 iOS |
| 内部网格 | 4 列，图标 52pt，其余规格与主网格一致 |
| 文件夹内右键 | App：同 4.2 + 「移出文件夹」；背景：`新建文件夹(嵌套? 见下)` |
| 嵌套文件夹 | **v1 不支持**（iOS 也到一层为止），文件夹内只能是 App —— 降低复杂度（P4） |

#### 创建与消除

| 方式 | 说明 |
|------|------|
| 拖拽合并 ★ | 编辑模式下，把 A 拖到 B 上重叠 ≥60% → 松手生成文件夹，弹出命名态 |
| 空白右键 | 「新建文件夹」→ 当前页末尾生成空文件夹（虚线框+＋图标），展开后可拖入 |
| 自动消失 | 最后一个 App 被拖出/移除后，文件夹自动删除 |
| 减号删除 | 编辑模式点文件夹的 ⊖：内含 App **退回桌面**按原顺序排列，文件夹删除（有确认 toast：「已移除文件夹，3 个 App 移回了桌面」） |

### 4.4 编辑模式（抖动模式）

```
        ╔══════════════════════════════════════════════════╗
        ║  拖动排序 · 拖到图标上可建文件夹      [＋ 添加] [✓ 完成] ║ ← 提示条 40pt
        ╠══════════════════════════════════════════════════╣
        ║                                                  ║
        ║    ⊖         ⊖         ⊖         ⊖         ⊖     ║
        ║   ┌────┐    ┌────┐    ┌────┐    ┌────┐  ┌────┐   ║
        ║   │▓▓▓▓│    │▓▓▓▓│    │▒▒▒▒│    │▓▓▓▓│  │▓▓▓▓│   ║
        ║   └────┘    └────┘    └────┘    └────┘  └────┘   ║
        ║   ~抖动~    ~抖动~   开发工具   ~抖动~   ~抖动~    ║
        ║                                                  ║
        ║   （⊖ 悬停时提示：「从桌面移除（不卸载 App）」）      ║
        ╚══════════════════════════════════════════════════╝
```

| 项目 | 规格 |
|------|------|
| 进入 | ① 长按任意图标 500ms（鼠标/触控板按住不动，移动超 8pt 视为拖拽而非长按）② 右键菜单「整理桌面…」 |
| 表现 | 所有格子小幅抖动（每格随机相位，±2°，0.25s/循环）；【减弱动态效果】时改为轻微呼吸淡入淡出 |
| 提示条 | 顶部 40pt：左侧引导文案，右侧 `＋ 添加` 与 `✓ 完成` 按钮 |
| 可做 | 拖拽排序（跨页：拖到边缘 500ms 自动翻页）、拖入/拖出文件夹（悬停文件夹 300ms 自动展开）、点 ⊖ 移除 |
| 不可做 | 单击图标不再启动（避免误触）；搜索栏隐藏 |
| 退出 | `✓ 完成` / Esc / 点击面板外 |
| 语义强调 | 一切删除仅作用于「桌面快捷方式」，**永远不会卸载真实 App**（文案与 tooltip 明示） |

        ╚══════════════════════════════════════════════════╝

> 上图左右两栏为同一覆盖层的示意合并；实际布局为**单列列表**：`图标 32pt ｜ 名称 ｜ 路径次文字`。

| 项目 | 规格 |
|------|------|
| 来源 | 扫描 `/Applications`、`~/Applications`、`/System/Applications`（.app 顶层，含本地化名），按名称排序 |

| 批量 | v1 不做多选（P1：单击即完成）；批量导入布局走设置中的「导入」 |
| 关闭 | `取消` / Esc |

## 5. 交互规范

### 5.1 指针输入（鼠标/触控板）

| 手势 | 位置 | 行为 |
|------|------|------|
| 左键单击 | 菜单栏图标 | 开/关面板 |
| 左键单击 | App 格子 | 启动（面板收起） |
| 左键单击 | 文件夹格子 | 展开 |
| 长按 500ms | App/文件夹格子 | 进入编辑模式 |
| 按住拖动 | 编辑模式 | 排序 / 合并建夹 / 移入移出文件夹 |
| 右键 | 任意处 | 上下文菜单（见 4.7） |
| 双指滑动 | 桌面 | 翻页 |
| 点击面板外 | — | 关闭面板（面板为 non-activating，不抢当前 App 焦点） |

### 5.2 键盘

| 键 | 上下文 | 行为 |
|----|--------|------|
| 任意字符 | 面板刚打开 | 打开搜索覆盖层并带入已输入的字符 |
| ⌘F | 桌面 | 打开搜索覆盖层 |
| ↑↓←→ | 搜索/网格 | 移动选中格（键盘选中态：label 色 10% 圆角框） |
| 回车 | 有选中/搜索结果 | 启动 |
| ⌘←/→ | 桌面 | 翻页 |
| Esc | 搜索/添加覆盖层 → 关闭；文件夹展开 → 收起；编辑模式 → 退出；否则 → 关面板（逐级回退） |
| ⌘, | 面板 | 打开设置 |

### 5.3 拖拽规则（编辑模式）

```
   拖起：原格半透明(30%)，拖影 scale 1.1 + 阴影
   移动：目标位置实时「抬起空位」，其余格子滑动让位（spring 0.2）
   悬停文件夹 300ms：自动展开该文件夹，可继续拖入；拖到卡片外 = 移出
   到达面板左/右边缘 500ms：自动翻页
   拖出面板边界松手：取消，回原位
   重叠判定：与另一格子中心距 < 格宽 60% → 合并成文件夹（一次提示命名）
```

### 5.4 焦点与关闭

- 面板打开不切换前台 App（non-activating panel），但面板自身可接收键盘；
- 关闭顺序：Esc 逐级回退（搜索 → 文件夹 → 编辑模式 → 面板）；
- 再次点击菜单栏图标 = 关闭；点击面板任意外部区域 = 关闭。

## 7. 状态与边界情况

| 情况 | 设计表现 |
|------|----------|
| App 已卸载/移动 | 图标替换为灰色通用 App 图标 + 右上角「?」角标；点击弹提示「未找到该 App，是否从桌面移除？」（移除/保留）；启动时后台校验一次 |
| App 改名/升级 | 以 bundle identifier 为准追踪，名称取当前本地化名，无感更新 |
| 重名 App | 名称照常显示，tooltip 显示完整路径 |
| 一页放不下 | 自动加页，页点出现 |
| 文件夹超 12 个 | 卡片内分页 + 卡片内页点 |
| 空文件夹 | 虚线框 + ＋ 图标，名称「新建文件夹」；展开后提示「拖入 App 或点击 ＋ 添加」 |
| 空桌面（首次） | 居中引导 + 「添加第一个 App」按钮（见 4.1） |
| 超小屏幕 | 最小高度 3 行；列数自动降为 4，格宽不变 |
| 菜单栏图标靠屏幕边缘 | 面板水平位置自动避让（钳制在屏内） |
| 系统深浅色切换 | 实时跟随，无需重启 |
| 减弱动态效果 | 关闭抖动/缩放/位移，仅保留淡入淡出 |
| 多显示器 | 面板出现在菜单栏图标所在的屏幕 |
| 面板打开时全屏 App | 正常悬浮显示（non-activating panel 可覆盖全屏空间） |

## 8. 数据结构建议

布局持久化为 JSON（`~/Library/Application Support/MenuHome/layout.json`）：

```json
{
  "version": 1,
  "pages": [
    [
      { "type": "app",    "id": "com.apple.Safari", "name": "Safari" },
      { "type": "folder", "name": "开发工具", "items": [
          { "type": "app", "id": "com.apple.dt.Xcode", "name": "Xcode" }
      ]}
    ]
  ],
  "settings": {
    "columns": 5,
    "iconSize": "m",
    "launchClosesPanel": true,
    "showRunningDot": true,
    "hotkey": "⌥⌘H",
    "launchAtLogin": true
  }
}
```

- App 以 **bundle identifier** 为主键（重装/升级不变），`name` 仅作缓存；
- 文件夹不设 id，靠在 pages 数组中的位置唯一标识；
- 导出/导入即整份 JSON，可手工备份。

## 9. SwiftUI 实现注记（不编码）

| 设计点 | 技术映射建议 |
|--------|--------------|
| 无 Dock 图标常驻 | `LSUIElement = YES` + `NSStatusItem`（比 `MenuBarExtra` 控制力更强） |
| 面板 | `NSPanel`，styleMask 含 `.nonactivatingPanel` + `.titled(去标题栏)`；`canBecomeKey = true` 保键盘可用（Raycast 同款做法） |
| 点击外部关闭 | 面板 resignKey 时关闭 |
| 毛玻璃 | `NSVisualEffectView`（material `.popover`）作面板背景，SwiftUI 内容叠上 |
| App 图标 | `NSWorkspace.shared.icon(forFile:)` —— 自带 macOS 圆角，直接渲染 |
| 运行中圆点 | `NSWorkspace.shared.runningApplications`（过滤 `activationPolicy == .regular`，按 bundle id 匹配） |
| App 列表 | `FileManager` 扫三个目录；备选 Spotlight `NSMetadataQuery` |
| 启动 App | `NSWorkspace.shared.openApplication(at:configuration:)` |
| 全局热键 | Carbon `RegisterEventHotKey`（或 HotKey SPM 包） |
| 面板内拖拽 | SwiftUI 手势自管理（不走 NSDragging pasteboard），更轻更可控；「从 Finder 拖入 .app」留 v2 |
| 持久化 | Codable JSON + 启动时 bundle id 校验 |
| 编辑抖动 | 每个 cell 独立 `PhaseAnimator/重复 rotate` 动画，随机延迟 |
