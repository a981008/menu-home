# MenuHome · UI 设计文档

> 一句话定位：**常驻 macOS 状态栏的「个人桌面」** —— 像 iPhone 桌面一样收纳常用 App，支持文件夹分类，一键直达。
>
> 版本 v1.0（已实现） · 2025-09 · 范围：仅 App 快捷方式 · 风格：macOS 26+ 液态玻璃 · 技术：SwiftUI + AppKit
>
> 变更记录：
> - **v1.1 —— 桌面取消分页 + 常驻搜索栏**：列数/行数 4/5/6 均可设置，内容超出可视区即垂直滚动（原生 ScrollView）；移除页点、⌘←/→、滚轮翻页与边缘翻页；旧多页布局加载时自动扁平迁移。面板顶部居中新增**常驻搜索栏**（胶囊玻璃，宽 200）；搜索覆盖层与「添加 App」**完全同构**（顶栏 + 分隔线 + 行列表），空查询直接列出全部（桌面文件夹 + 全部本机 App）。
> - **v1.0 —— 按已交付实现全面校订**：液态玻璃（glassEffect interactive + 连续曲率圆角）、控制中心式面板开合、拖拽改「提起」模型且**随时可拖**（无需编辑模式）、文件夹卡片 3×3 分页 + 从图标缩放展开（iOS 同款）+ 卡片内拖动/拖出移出、缩略图与主网格严格等比例、名称单行、Finder 拖入 .app、文件夹 UUID 持久化。
> - v0.2 —— 搜索栏不再常驻，改为按需弹出的覆盖层（面板打开后直接敲键盘或 ⌘F 呼出）；设计定稿，进入编码阶段。

## 1. 产品概述与设计原则

### 1.1 要解决的问题

- 常用 App 散落在 Launchpad / Finder / Spotlight 里，鼠标路径太长；
- Dock 放不下也分不了类；
- 想要一个「随叫随到、一眼看清、一击直达」的个人应用面板。

### 1.2 设计原则（做所有取舍时的判断依据）

| # | 原则 | 含义 |
|---|------|------|
| P1 | **一击即达** | 菜单栏图标 → 点 App，全程 2 次点击完成任务；任何功能入口不超过 2 层 |
| P2 | **似曾相识** | 交互隐喻全部来自 iOS 桌面：长按进编辑、拖拽建文件夹、点文件夹展开。零学习成本 |
| P3 | **原生融入** | 毛玻璃材质、系统字体、跟随深浅色、右键菜单风格与 macOS 一致，像系统自带功能 |
| P4 | **克制** | 面板只有一个主界面（桌面）。没有侧边栏、没有标签页、没有多余按钮 |

## 2. 信息架构与界面清单

```
MenuHome
├── 0. 菜单栏图标（常驻唯一入口）
│     ├── 左键单击 → 开/关「主面板」
│     └── 右键 → 快捷菜单（打开面板 / 设置 / 退出）
├── 1. 主面板「桌面」 ★唯一主界面（单页滚动网格）
│     ├── App 格子（单击启动）
│     ├── 文件夹格子（单击展开 → 2. 文件夹覆盖层）
│     ├── 搜索（键盘直入，实时过滤）
│     └── 滚动（内容超出可视行数即垂直滚动）
├── 2. 文件夹展开层（面板内覆盖层，非新窗口）
├── 3. 编辑模式（抖动模式，面板内状态；纯视觉辅助 —— 拖拽随时可用）
├── 4. 添加 App 覆盖层（面板内，编辑模式/右键进入）
├── 4b. Finder 拖入 .app → 加入当前页（面板描边高亮）
├── 5. 设置窗口（独立小窗口）
└── 6. 右键菜单（贯穿 1–4 的上下文操作）
```

**关键形态决定**：文件夹展开、编辑模式、添加 App 都是**面板内的覆盖层/状态**，不是新窗口 —— 保证「桌面」这个空间隐喻始终成立，用户永远不会迷路。

## 3. 核心用户旅程

| 场景 | 路径 |
|------|------|
| 日常启动 | 点菜单栏图标 → 看到桌面 → 点 App → 启动，面板自动收起 |
| 归类整理 | 直接把 A 拖到 B 上 → 悬停片刻出现合并态 → 松手自动建文件夹 → 点名字命名 |
| 找 App | 面板打开后直接敲键盘 → 实时过滤 → 回车启动第一个结果 |
| 新装了 App | 右键空白处 →「添加 App…」→ 搜索勾选 → 加入当前页空位 |
| App 被卸载了 | 图标变灰带「?」→ 点击时提示「未找到，是否从桌面移除？」 |

### 4.0 菜单栏图标（常驻入口）

```
  macOS 菜单栏（放大示意）：
  ┌────────────────────────────────────────────────┐
  │   ···  [ ⌂ ]   ···   🔋82%   📶   ⌕   21:58   │
  └─────────▲──────────────────────────────────────┘
            │ MenuHome 图标：18×18 迷你 App 图标（彩色渐变圆角底 + 白色房子）
```

| 项目 | 规格 |
|------|------|
| 图形 | **迷你 App 图标**（v1.1 变更，替代小房子轮廓）：系统蓝→靛蓝渐变圆角底（半径 4.5）+ 顶部玻璃高光 + 白色实心房子 + 靛蓝门 —— 一眼像一个 App，点开像打开它的菜单 |
| 渲染 | 非模板彩色图（程序化绘制，矢量分辨率无关）；细黑描边 15% 在浅色菜单栏上提供轮廓感 |
| 尺寸 | 18×18pt |
| 状态 | 常规（彩色）/ 点击（系统默认高亮胶囊）/ 面板展开时收起面板 |
| 左键 | 开/关面板（toggle），面板锚定图标正下方 |
| 右键 | 快捷菜单：`打开面板` ｜ `设置… ⌘,` ｜ `退出 MenuHome` |
| 可选 | 全局热键呼出/收起面板（默认 `⌥⌘H`，设置中可录制） |

> 设计取舍：不放「未读/数量」角标类信息 —— 这是个纯启动器，图标永远安静。

#### 结构与栅格（以默认 5 列 × 5 行 = 25 格可视为例）

| 区域 | 规格 |
|------|------|
| 面板整体 | 宽 = 40(左右边距) + 78(格宽)×N + 12(列距)×(N−1) → 4列 388 / **5列 478** / 6列 568；高 = 42(搜索栏区) + 16 + (94×行数 − 14) + 12 → 4行 432 / **5行 526** / 6行 620 |
| 常驻搜索栏 | 顶部居中：宽 200 × 高 30 胶囊玻璃（圆角 15），🔍 + 「搜索 App」占位；点击进入搜索覆盖层；编辑模式时让位给整理条 |
| 网格 | 单列表从左上角填充，行/列距 12/14，单元格见 [4.2](#42-app-格子cell)；内容超出可视行数即垂直滚动 |
| 滚动 | 原生 ScrollView（带指示器）；内容不足一屏时面板保持满屏高度 |
| 搜索入口 | 顶部常驻搜索栏（点击）+ 按需覆盖层（键盘直入 / ⌘F）；覆盖层与「添加 App」同构（顶栏 + 行列表），空查询列出全部 App |
| 出现动效 | 控制中心式：以菜单栏图标为锚点 scale 0.7→1 + 淡入（spring 0.32/0.82）；关闭反向缩回图标方向 |

#### 滚动（v1.1 起不分页）

| 操作 | 行为 |
|------|------|
| 触控板双指滑动 / 鼠标滚轮 | 垂直滚动（原生 ScrollView，带指示器） |
| 内容超出可视行数 | 直接滚动查看；单列表存储，无页的概念 |
| 拖拽 + 滚动 | 拖拽坐标系基于滚动内容，滚到哪拖到哪 |

#### 搜索（常驻栏 + 覆盖层）—— v1.1 变更

顶部居中常驻搜索栏（胶囊玻璃，宽 200 × 高 30），点击即进入搜索覆盖层；也可键盘直入或按 `⌘F`。覆盖层与「添加 App」**完全同构**：

- **触发**：点击常驻搜索栏 / 面板打开后直接敲键盘任意字符 / `⌘F`；
- **呈现**：与「添加 App」同一骨架 —— 顶栏（🔍 + 标题 + 输入框 + 取消）/ 分隔线 / 行列表；输入框同款（roundedBorder / 12pt / 宽 200，自动聚焦并带入已敲入字符）；
- **空查询 = 全量列表**：桌面文件夹在前 + 全部本机 App（含未添加到桌面的）—— 和「添加 App」一样把所有都列出来；
- 实时过滤：按名称匹配（桌面文件夹 + 全部 App）；行副标注「文件夹 · N 个 App」/ 所在目录；
- 行样式与「添加 App」一致：图标 32 + 名称 13pt + 副行 10pt，悬停高亮；点 App 启动、点文件夹展开；
- 回车 = 启动第一个结果（文件夹则展开）；
- Esc / 取消按钮 = 关闭回桌面（不关面板）；
- 无结果：与「添加 App」空态一致「没有匹配「xx」的 App」+「添加 App…」入口。

#### 网格中的文件夹格子

```
   ┌────┐        iOS 同款隐喻：圆角矩形内 3×3 微缩图标
```

| 项目 | 规格 |
|------|------|
| 卡片 | 宽度自适应 = 3 列主网格格子 + 2×列距 + 左右各 16pt；高恒定（标题 + 3 行网格 + 页点区）；液态玻璃（glassEffect interactive），连续曲率圆角 26 |
| 打开动效 | **iOS 同款**：点击时记录文件夹图标的矩形，卡片**以图标为锚点、从图标尺寸缩放展开**（spring 0.35/0.8），背景压暗淡入；右键「打开」「移入新文件夹」同源 |
| 关闭 | 点背景 / Esc / 再点该文件夹图标；卡片**缩回图标**（spring 0.25/0.85） |
| 重命名 | 单击卡片标题 → 行内文本框（预选中原名），回车/失焦确认；同 iOS |
| 内部网格 | **3 列 × 3 行 = 9 格/页**；格子/间隙/图标尺寸与主网格**逐像素一致**（跟随图标大小设置）；超过 9 个分页：页点 + 卡片内横滑（拖动图标时不翻页） |
| 图标内缩略图 | 3×3 微缩图标与主网格**严格等比例**：3×mini + 4×gap = 盒边长，mini:gap = 图标:(格内边距+列距)；间隙/边距均匀，从左上角排起 |
| 文件夹内拖动 | 卡片内可拖动排序（拖影跟随 + 目标格放大高亮）；**拖出卡片边界 = 移出文件夹**退回桌面末尾；拖出唯一 App 时文件夹自动删除 |
| 文件夹内右键 | App：同 4.2 + 「移出文件夹」；背景：`新建文件夹(嵌套? 见下)` |
| 嵌套文件夹 | **v1 不支持**（iOS 也到一层为止），文件夹内只能是 App —— 降低复杂度（P4） |

#### 创建与消除

| 方式 | 说明 |
|------|------|
| 拖拽合并 ★ | **任意时刻**（无需编辑模式）：拖起 A 悬停到 B 上 400ms 出现合并态（B 放大 1.15）→ 松手生成文件夹；app+app 建新夹、app 入夹、夹并夹 |
| 空白右键 | 「新建文件夹」→ 当前页末尾生成空文件夹（虚线框+＋图标），展开后可拖入 |
| 自动消失 | 最后一个 App 被拖出/移除后，文件夹自动删除 |
| 减号删除 | 编辑模式点文件夹的 ⊖：内含 App **退回桌面**按原顺序排列，文件夹删除（有确认 toast：「已移除文件夹，3 个 App 移回了桌面」） |

## 5. 交互规范

### 5.1 指针输入（鼠标/触控板）

| 手势 | 位置 | 行为 |
|------|------|------|
| 左键单击 | 菜单栏图标 | 开/关面板 |
| 左键单击 | App 格子 | 启动（面板收起） |
| 左键单击 | 文件夹格子 | 展开 |
| 长按 350ms | App/文件夹格子 | 进入编辑模式 |
| 按住拖动 | **任意模式** | 排序 / 合并建夹 / 移入移出文件夹（提起模型，见 5.3） |
| 右键 | 任意处 | 上下文菜单（见 4.7） |
| 双指滑动 / 滚轮 | 桌面 | 垂直滚动 |
| 点击面板外 | — | 关闭面板（面板为 non-activating，不抢当前 App 焦点） |

### 5.2 键盘

| 键 | 上下文 | 行为 |
|----|--------|------|
| 任意字符 | 面板刚打开 | 打开搜索覆盖层并带入已输入的字符 |
| ⌘F | 桌面 | 打开搜索覆盖层 |
| ↑↓←→ | 搜索/网格 | 移动选中格（键盘选中态：label 色 10% 圆角框） |
| 回车 | 有选中/搜索结果 | 启动 |
| Esc | 搜索/添加覆盖层 → 关闭；文件夹展开 → 收起；编辑模式 → 退出；否则 → 关面板（逐级回退） |
| ⌘, | 面板 | 打开设置 |

### 5.3 拖拽规则（提起模型，任意模式可用）

```
   拖起：图标从网格中「提起」（其余格子立即补位，全程不再换位）；
         拖影 scale 1.1 + 阴影跟随光标
   移动：光标所在格占用者稳定不动，该格放大 1.15 示意
   合并：悬停目标图标 400ms → 进入合并态（描边高亮）→ 松手合并成文件夹
   放置：松手插入光标所在格（该格图标向后让位）；无效区域取消回原位
   文件夹卡片内：拖动排序；拖出卡片边界 = 移出文件夹退回桌面
```

### 5.4 焦点与关闭

- 面板打开不切换前台 App（non-activating panel），但面板自身可接收键盘；
- 关闭顺序：Esc 逐级回退（搜索 → 文件夹 → 编辑模式 → 面板）；
- 再次点击菜单栏图标 = 关闭；点击面板任意外部区域 = 关闭。

## 8. 数据结构建议

布局持久化为 JSON（`~/Library/Application Support/MenuHome/layout.json`）：

```json
{
  "version": 1,
  "pages": [
    [
      { "type": "app",    "id": "com.apple.Safari", "name": "Safari" },
      { "type": "folder", "id": "UUID", "name": "开发工具", "items": [
          { "type": "app", "id": "com.apple.dt.Xcode", "name": "Xcode" }
      ]}
    ]
  ],
  "settings": {
    "columns": 5,
    "iconSize": "m",
    "launchClosesPanel": true,
    "showRunningDot": true,
    "hotkey": "⌥⌘H",
    "launchAtLogin": true
  }
}
```

- App 以 **bundle identifier** 为主键（重装/升级不变），`name` 仅作缓存；
- 文件夹有稳定 UUID（FolderEntry.id），展开/重命名/拖入拖出都按 id 寻址；
- 导出/导入即整份 JSON，可手工备份。

## 9. SwiftUI 实现注记（不编码）

| 设计点 | 技术映射建议 |
|--------|--------------|
| 构建环境 | 本机 CLT 6.4 **SwiftPM 不可用** → 一律 `scripts/build_app.sh`（swiftc 直编）；27 SDK 的 **SwiftUIMacros 插件缺失** → `@State` 手工脱糖 —— 详见仓库根 **AGENTS.md** |
| 无 Dock 图标常驻 | `LSUIElement = YES` + `NSStatusItem`（比 `MenuBarExtra` 控制力更强） |
| 面板 | `NSPanel`，styleMask 含 `.nonactivatingPanel` + `.titled(去标题栏)`；`canBecomeKey = true` 保键盘可用（Raycast 同款做法） |
| 点击外部关闭 | 面板 resignKey 时关闭 |
| 液态玻璃 | SwiftUI `glassEffect(.regular.interactive(), in: RoundedRectangle(cornerRadius:, style: .continuous))`，统一入口 `Theme.liquidGlass`；部署目标 macOS 26+，无 #available 回退 |
| App 图标 | `NSWorkspace.shared.icon(forFile:)` —— 自带 macOS 圆角，直接渲染 |
| 运行中圆点 | `NSWorkspace.shared.runningApplications`（过滤 `activationPolicy == .regular`，按 bundle id 匹配） |
| App 列表 | `FileManager` 递归扫四个目录（两层深度）；本地化名经 InfoPlist.loctable/strings 按用户语言解析 |
| 启动 App | `NSWorkspace.shared.openApplication(at:configuration:)` |
| 全局热键 | Carbon `RegisterEventHotKey`（或 HotKey SPM 包） |
| 面板内拖拽 | SwiftUI DragGesture（**提起模型**，不走 NSDragging pasteboard）；「从 Finder 拖入 .app」已实现：`onDrop(.fileURL)` → `AppScanner.entry(atPath:)` |
| 持久化 | Codable JSON + 启动时 bundle id 校验 |
| 编辑抖动 | 每个 cell 独立 `PhaseAnimator/重复 rotate` 动画，随机延迟 |
